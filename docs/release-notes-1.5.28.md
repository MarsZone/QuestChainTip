# 1.5.28

**任务日志里开详情窗改成 Shift+右键，左键完整让给 Questie 的隐藏任务**

## 为什么又改

1.5.27 已经把 Shift 从任务日志里「放行」了，但你实测 Shift+左键**还是**藏不了任务，
而且照旧冒「插件导致界面行为失效」。左键这条路不能再碰了 —— 干脆换个手势。

## 现在的操作

| 你在哪 | 按什么 | 结果 |
|---|---|---|
| 任务日志里，鼠标停在任务行上 | **Shift+右键** | 打开这条任务的整条任务链 |
| 任务日志里 | Shift+左键 | 什么都不做，**完整留给 Questie 的隐藏/显示任务** |
| 任务日志里 | 按 Shift | 聊天框提示一次「开窗改用 Shift+右键」（60 秒一次、每次登录最多 3 条） |
| 任务日志里 | Alt | 仍然能开窗（`/qct logkey` 可改） |
| 世界地图的任务图标 | Shift | 照旧开窗 |

Shift+右键在游戏里原本没有用途（右键单独按是交互/自动攻击），绑走不影响任何东西。
绑定会在登录时自动重新应用，换角色也不用管。

## 如果右键没反应

说明这一行没被认出来。鼠标往下挪一点点、压在任务名文字上再按一次。
还是不行就敲 `/qct qlog`，把「鼠标下:」那行发我 —— 现在它会打印光标压到的帧名与尺寸。

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

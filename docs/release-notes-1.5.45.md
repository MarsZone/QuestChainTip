# 1.5.45

含 1.5.44 的改动，外加一个必须马上修的问题。

## 1.5.44 的改动：消掉「Questie 的框闪一下」

之前是「先让 Questie 画 → 我们 0.12 秒内收掉」，那一瞬就是闪。
现在直接包住 Questie 的 `MapIconTooltip.ShowOnTooltip`：

- 能认出任务 + 我们的面板画得出来 → 我们画，**不调用原函数**，Questie 一个像素都不显示
- 认不出任务 / 画不出来 / 功能关着 → 原样调用，Questie 照常显示
- 拿不到模块时自动退回轮询方式

## 1.5.45 修：接管后「松开 Shift 不弹窗」

副作用来了：提示框被我们拦掉、根本没显示 → 松开 Shift 时拿不到持有者 →
找不到「鼠标下这个图标」，于是什么都不弹。

- Shift 松开 / Alt 开窗 / 自定义键开窗：拿不到持有者时，**用「接管中的图标」顶上**
- 回归测试新增三条：接管状态下「按下不弹 / 松开弹出 / 弹的是那个任务」

## 现在的效果

- 悬停图标：**只有我们那张框**，不闪
- 松开 Shift：弹出该任务的整条链
- 光标移开：面板收起，Questie 的提示框恢复正常

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

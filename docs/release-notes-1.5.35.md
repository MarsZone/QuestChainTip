# 1.5.35

**手势改用 Alt（Shift 交还 Questie）+ 面板贴着光标**

## 1) 为什么满屏都是字

你按住 Shift 想看任务链，但 **Questie 也在监听 Shift** —— 它靠 Shift 把地图提示框展开成
「任务描述 / 任务奖励 / 后续任务」那一大段。于是同一次按键，先糊出一屏 Questie 的详情，
再弹我们的窗。这不是我们多画了东西，是两个插件在抢同一个键。

**现在地图上也改用 Alt**（和任务日志一致）：按住 Alt 悬停图标 → 面板；松开/点击 → 详情窗。
Shift 完全让给 Questie。

老存档会**自动迁移一次**（Shift → Alt），登录时会提示一句：
```
手势已改用 Alt：地图上按住 Alt 悬停任务图标，任务日志里按住 Alt 点任务行。
Shift 交还给 Questie…… 要改回来：/qct key shift
```

## 2) 面板离鼠标太远

以前面板贴在 `GameTooltip` **下面**。Questie 那个提示框一个 NPC 图标能列十几条，
又高又长，我们的面板就被顶到离鼠标几百像素的地方 —— 看着像「鼠标在这、面板在那边」。
现在**直接贴着光标弹**，右下角偏移 18px，贴屏幕边就自动翻到另一侧。

## 3) 光标已经离开图标还在画

Questie 的提示框收得比鼠标慢半拍，那半拍里插件还拿着旧图标画面板。
现在加了矩形判断：**光标不在那个图标身上就不画**。

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

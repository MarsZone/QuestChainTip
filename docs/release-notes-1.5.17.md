## 任务链提示 1.5.17 / Quest Chain Tip 1.5.17

任务日志 Alt 不再依赖提示框；血量加兜底；新增两个诊断命令。

---

### 任务日志 Alt 不弹 / Alt still did nothing

上一版靠 `GameTooltip` 的 owner 找任务行。但有的 UI 包把任务日志的提示框换成自绘的，`GameTooltip` 里根本没有 owner，于是永远找不到目标。

现在改成：**鼠标进入任务行时记下按钮和任务 ID**，按 Alt 时只看「鼠标是否还停在那行上」（`MouseIsOver`），完全不碰 tooltip。

顺带加了一层保护：如果鼠标其实停在地图图标上，不会拿几十秒前悬停过的任务行来开窗。

### 血量不显示 / Health still hidden

加了兜底：如果框体里找不到 StatusBar（自定义 UI 常用 Frame + 贴图做血条），就在框体上叠一层独立 Frame，层级抬到所有子帧之上，文字放框体中央。

位置不完美（不如贴着血条准），但至少能看见。另外文字统一设了 220px 宽度，避免某些客户端上 FontString 按 0 宽排版、字挤成一条看不见。

### 新增诊断命令 / New diagnostics

如果还是不显示，请跑这两条把输出发我：

```
/qct health    框体名、血条找到没有、文字内容/可见性/父级、子帧列表
/qct qlog      配置的键、提示框状态、持有者、最近悬停的按钮和任务 ID
```

有了这两个输出，就能确定是「没找到血条」「文字被盖住」还是「按钮没钩上」。

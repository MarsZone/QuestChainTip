# 新手盒子入驻申请材料包

> 目标：一次性过审。审核看的是「这个人是不是真的在做内容 + 东西是不是原创能用」，不是看插件多牛。
> 你现在 B 站有几十万播放，最难的那条已经过了，剩下的只是把材料摆整齐。

---

## 一、四条条件，你的判定

| 条件 | 判定 | 依据 |
|---|---|---|
| ① 内容平台单条 ≥3,000 播放（近30天）或累计 ≥50,000 | ✅ **过** | B 站几十万播放，累计口径远超 50,000 |
| ② 已发布过可正常运行的原创内容，且已发布于其他平台 | ⚠️ **需补** | 插件能跑、原创，但「其他平台」目前只有 GitHub，需补 Wago.io |
| ③ 非搬运 / 非无实质优化的二次打包 | ✅ **过** | 从 Questie 源码层面重写判定逻辑，非打包整合 |
| ④ 提供数据证明材料 | ⚠️ **需准备** | 见下面第二节，按清单截 |

**唯一要动手的两件事**：先去 Wago 发一版拿到页面链接，再按清单截图。

---

## 二、先补条件②：Wago.io 上传（5 分钟）

Wago 不需要审核、不卡 `Interface: 16001`，传完立刻有公开页面，是条件②最省事的凭据。

1. 打开 `https://wago.io`，右上角 `Sign In`（用 GitHub 账号直接登录最快）
2. 右上角头像 → `New Addon`
3. 依次填：
   - **Name**：`Quest Chain Tip`
   - **Game**：World of Warcraft
   - **File**：上传 `E:\AI\wowaddones\QuestChainTip\dist\QuestChainTip-1.5.9.zip`
     （版本号会自动从 `toc` 读成 1.5.9，不用手填）
   - **Description**：粘 `docs/listing-en.md` 的详细说明
   - **Icon**：`docs/icon-128.png`
   - **Screenshots**：`docs/screenshots/` 三张
   - **Project URL**：`https://github.com/MarsZone/QuestChainTip`
4. 发布后复制地址栏的 addon 页面链接，形如 `https://wago.io/xxxxxxxx`

> 如果 Wago 提示需要先创建 author profile，按提示填名字即可，不用审核。
> 这一步完成后，条件②的「其他平台」就有一个国际插件站的公开页面，比 GitHub 有说服力。

## 五、审核可能追问的三个点

**Q1：这个插件依赖 Questie，算不算二次打包？**
> 不算。它不包含 Questie 的任何文件，是独立插件，只是调用 Questie/QuestieDB 的公开接口取数据。
> 逻辑上等同于「Questie 的一个扩展」，和 WeakAuras 依赖库文件是同一类关系。

**Q2：Interface 16001 是什么版本？**
> 永久60 客户端（1.15.x 系）的版本号，和 QuestieDB_Forever 一致。
> 不是官方 Classic Era 的 115xx，所以 CurseForge 会识别不了，这也是优先发国内平台的原因。

**Q3：下载量这么少，怎么证明有人用？**
> 插件今天刚发布第一版，下载数据还在积累。
> 账号侧的证明在 B 站（累计几十万播放），插件侧的价值可以用实机截图和源码验证。

## 六、提交之后

1. 审核通常 1–3 个工作日，通过后账号解锁上传入口，之后发新插件**不用再审**
2. 同时可以先发 NGA 插件区——那里不需要审核，发帖即上线，
   是永久60 玩家真正的聚集地，能立刻拿到真实反馈和下载量
3. 入驻通过后再上传插件时，文案直接用 `docs/listing-zh.md`，字段对照见
   `docs/publish-checklist.md` 第一节

## 七、一句话总结

条件①你已经过了，②靠 Wago 补一个页面链接，③④靠截图和上面那段话术。
真正要做的事只有两件：**传一次 Wago**、**截四张图**。别在「插件够不够好」上纠结，审核不看这个。

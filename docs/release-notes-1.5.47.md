# 1.5.47

**修：松开 Shift 弹出详情窗后，悬停面板还赖在旁边**

你截图里左边是详情窗、右边是悬停面板，两个框说的是同一条链。

## 原因

Shift 松开时，Questie 会重建它自己的地图提示框 —— 我们的拦截钩子于是又跑了一遍，
**重新画了一次悬停面板**；而详情窗已经开着同一条链，就叠在一起了。

## 修法

接管前先看一句：**详情窗已经开着这条链吗？**

- 是 → 只按掉 Questie 的框，**不画悬停面板**（详情窗已经够看）
- 否 → 照旧：只画悬停面板

轮询兜底那条路也加了同样的判断。回归测试补了三条：窗口开着时调用 `ShowOnTooltip`
—— 悬停面板必须是收起的、Questie 的框也不许出现。

## 现在的行为

| 你在做什么 | 屏幕上 |
|---|---|
| 鼠标停在地图图标上 | 只有悬停面板（贴光标） |
| 松开 Shift | 只有详情窗，面板自动收起 |
| 关掉详情窗、继续悬停 | 悬停面板回来 |
| 鼠标移开 | 都收起，Questie 的提示框恢复 |

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

# 1.5.33

**背包物品查任务：本服自定义物品也能定位了**

## 你截图说明的情况

```
GetItem -> 调用成功 | 名字: 注入巫毒的神器 | 链接: [...]
物品 ID: 270333
LibQuestieDB: 有 | Item.startQuest: 有
  这件物品开启的任务: nil
```

代码这条路**已经通了**：物品认出来了、链接抠出了 `270333`、`startQuest` 接口也在。
问题在数据：**270333 是本服的自定义物品，QuestieDB 是原版数据，里面没有它的记录。**

## 所以改成三级定位（从准到宽）

1. `startQuest` —— 原版物品，最准
2. `relatedQuests` —— 相关任务，退一步
3. **任务日志里「目标文本提到这个物品名」** —— 自定义任务的目标文本是客户端给的，
   自定义物品照样能在里面找到（比如「把注入巫毒的神器带回给祭司」）

## `/qct item` 也补全了

现在会打印：

- DB 里的物品名（判断这件物品数据库到底认不认识）
- `startQuest ->` 具体返回了什么
- `relatedQuests ->` 前 5 个
- 最终定位到的任务 **和来源**（`QuestieDB startQuest` / `relatedQuests` / `任务日志目标文本`）

## 用法

鼠标停在任务物品上按住 Alt。认不出来时什么都不弹，敲 `/qct item` 能看到每一环的结果。

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

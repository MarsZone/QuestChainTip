1.5.37 把「隐藏 Questie 提示框」的默认值设成 `true`，并且**存进了 SavedVariables**。
1.5.39 我只改代码里的默认值 —— 对已有存档**不生效**（键已经存在，默认值不会覆盖它）。

这一版强制复位一次：

```
hideQuestieTip = false
```

只改这一次，之后你自己在设置里勾的不会被覆盖。

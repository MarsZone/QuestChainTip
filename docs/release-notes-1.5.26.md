# 1.5.26

**撤掉「血量数值显示」——它一直在扫框体找血条**

这个功能为了把「当前 / 最大」贴到目标血条上，得不停扫框体、跟位置、目标换了还要重挂，
玩家反馈太费。整个功能停用。

## 撤掉的东西

- `Health.lua` 从 `QuestChainTip.toc` 的加载列表里注释掉 —— 模块根本不加载，一点开销都没有
  （文件还在仓库里，想要就删掉 toc 里那一行注释）
- 设置面板里「显示血量数值（目标/焦点血条上）」「血量数值可拖动（自由摆放）」两行撤掉，
  面板高度从 700 缩回 640
- `/qct health` 命令和帮助里的 6 行说明一并撤掉，现在敲这个命令只会看到一句：
  「血量数值显示已停用（这个功能会一直扫框体找血条，太费）。」

## 没动的

任务链、悬停面板、详情窗、小地图按钮、世界地图 / 任务日志的快捷键 —— 全部照旧。
1.5.25 那个「Alt 弹出上次 Shift 的任务」的修复也还在。

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。
（旧目录里的 `Health.lua` 留着不用删，toc 不加载它就不会跑。）

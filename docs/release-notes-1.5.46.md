# 1.5.46

**修：接管之后，任务日志里按 Alt 不弹窗了**

## 原因

1.5.45 为了修「Shift 松开不弹」，加了一条兜底：

> 拿不到提示框持有者时，用「接管中的图标」顶上

但这条**没限制必须在地图上**。于是你在任务日志里按 Alt：

1. 提示框没持有者（自绘日志）
2. 插件拿「上次地图上接管的图标」顶上 → 开出那个任务、然后 `return`
3. 任务日志那条路（扫行 / 找选中的那条）根本走不到

## 修法

- 兜底加前置条件：**必须世界地图开着**才用接管中的图标
- 解析包一层 `pcall`：图标被回收也不会把整条按键处理链路打断
- 回归测试补一条：接管过地图图标后回到日志按 Alt，仍然开日志那一行（修复前是红的）

## 现在三条路互不干扰

| 场景 | 行为 |
|---|---|
| 地图图标上松开 Shift | 开这个图标的链 |
| 任务日志里按 Alt | 开光标那一行（或选中的那条） |
| 背包物品上按 Alt | 开这件物品开启的链 |

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

# 1.5.69

这一版是一整串连续修复的合集（1.5.48 → 1.5.69），主要围绕「地图上的任务提示」重做。

## 一、地图图标：只显示我们的面板（不再被 Questie 的一屏字糊住）

- 悬停 Questie 的地图图标时，**先我们画，再把它的提示框按掉**（默认开，设置里可关）
- 铁律：**只有我们的面板真的显示出来，才允许按掉它的框**；画不出来就立刻交还，绝不出现两边都空
- 拦在 Questie 绘制之前（包 `MapIconTooltip.ShowOnTooltip`），**不会先闪一下**；
  拿不到那个模块时自动退回轮询方式
- 我们主动关提示框时用 `suppressTipHide` 屏蔽 `OnHide` 钩子，避免把自己的面板一起收掉

## 二、悬停面板：排版与手感

- 抬头下面新增 **接取 / 交付**（NPC + 地图）
- 区块前后留白、区块标题改暗金色、正文缩进统一、后续 `→` / 前置 `←`
- 奖励拆行：经验+金钱 / 物品 / 声望
- 面板**贴着光标**（不再挂在 Questie 那个高提示框下面），并且**每帧跟随鼠标**（30fps 限流）
- 光标离开图标（>180px 或进入任务列表）就收起；关地图时一并清干净
- 同一点位有多个任务：**并列列出**其他任务（名字 + 一句后续/前置，按 NPC 名过滤，不会串到隔壁）

## 三、详情窗

- **屏幕居中**（水平 + 垂直），不再从角落冒出来；下一帧按真实尺寸再摆一次，首次开窗也不偏
- 同一 NPC 有多个任务时，标题下出现**页签**：名字完整显示、当前页签暗金 + 下划线、超宽自动换行，点一下切到那条任务
- 详情窗开着同一条链时，悬停面板不再叠在上面

## 四、手势分工

- **地图画布**：松开 Shift → 详情窗；Alt 在地图上不弹
- **任务列表**（含地图右边那个）：Alt → 详情窗；Shift 在列表里不弹
- 任务列表认不出帧/矩形时，按**提示框标题**反查任务（自绘列表也能用）
- 背包物品：Alt 查这件物品开启的链（1.5.33 起支持本服自定义物品，靠目标文本匹配）

## 五、链路

- 后续任务改成**广度优先**：一个任务分出多条支线时全部列出（以前只跟一条线）
- 关地图瞬时也会收掉残留的提示框（按 M 不会再冒出任务框）

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

## 正文（粘到「请输入内容」那个大框）

```
【它解决什么问题】

Questie 只对「还没接」的任务显示描述、奖励和后续任务链。已经接下的任务，鼠标移上去只有完成条件——你不知道后面还有几环、给什么奖励、要不要跑副本。

这个插件补的就是这块空白：可接的、正在做的、已完成的，所有任务都能看到完整信息。

【世界地图上悬停任务图标：补全面板】

· 任务描述（显示行数可配置）
· 奖励：经验、金钱、物品（带品质颜色）、声望
· 后续任务链（层数可配置，默认 3 层）
· 前置任务

默认只在世界地图上出现，设置里可以改成「关闭」或「全部位置」。
小地图上永远不弹；聊天框里也永远不弹，不会挡住 Shift+点击复制任务链接。

【世界地图上按住快捷键（默认 Shift，可改成 Ctrl / Alt）：整条链详情窗】

每条任务一张卡片：

· 完成条件（目标列表）
· 奖励（经验 / 金钱 / 物品，物品可悬停看属性、左键点开详情）
· 任务详情（任务文本）
· 在哪接、在哪交（NPC 名字 + 所在区域）
· 是否副本任务 / 团本任务 / 精英任务
· 任务状态（可接 / 进行中 / 已完成）

默认折叠已完成的任务，右上角一键展开全部。窗口可拖动、可滚动，Esc 关闭。
关闭世界地图时窗口会自动收起，不会留在屏幕中间。
窗口宽度可以在设置里调（自动 / 窄 / 标准 / 宽），默认按屏幕宽度自适应；
悬停面板也有三档宽度，任务名和奖励物品不容易被迫折行。

【任务日志列表：按住 Alt 看整条链】

鼠标停在任务列表的某一行上，按住 Alt（默认）打开整条任务链详情窗。
Shift 留给原生的「把任务链接贴到聊天框」，不会被抢。快捷键可改（Alt / Ctrl / 关掉）。

【可选：血量数值 / 小地图按钮】

· 血量数值：目标、焦点框体的血条上显示「当前 / 最大」，默认关闭
· 小地图按钮：左键打开设置，可拖动，可在设置里关掉

如果 Shift 和别的插件（比如 Questie 的隐藏任务标记）冲突，可以在设置里把快捷键改成 Ctrl、Alt，
或者点「自定义…」直接按一个想用的键（F、数字键、Ctrl+1 都行），也可以关掉按键触发只保留悬停面板。

【界面语言】

自动跟随客户端：简体、繁体、英文三套文案。繁体客户端不再显示方块，英文客户端也能正常使用。
也可以手动切换：/qct locale zhCN

【依赖】

· 必需：Questie（提供任务数据）
· 可选：QuestieDB 独立插件。装了之后，还没接取的后续任务也能显示物品奖励

本插件不重复打包任何任务数据。

【适用版本】

魔兽世界 永久 60（1.60.1）

【命令】

/qct                 打开设置
/qct depth 5         悬停显示 5 层后续任务
/qct detail          打开当前任务的详情窗（也可以直接跟任务 ID）
/qct locale zhCN     手动切换界面语言（zhCN / zhTW / enUS / auto）
/qct key ctrl        详情窗快捷键改成 Ctrl（也支持任意键：/qct key f）
/qct width 720       详情窗宽度固定 720（auto 为按屏幕自适应）
/qct pwidth 460      悬停面板宽度 460
/qct explain         开关聊天框诊断信息（排查问题用，默认关）
/qct why             打印当前状态诊断
/qct log             打印后台日志

【反馈】

遇到问题请附上 /qct why 和 /qct log 的输出，能直接定位是哪一步没识别到。

【更新日志】

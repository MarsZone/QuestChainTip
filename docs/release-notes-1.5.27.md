# 1.5.27

**修两个「抢按键」的问题：Shift 抢了 Questie 的隐藏任务，Alt 在野外也弹窗**

## 1) Shift+点击没法隐藏任务了

任务日志里 **Shift+点击是 Questie 的「隐藏/显示任务」**。我们一按 Shift 就把详情窗弹出来，
窗口盖在日志上，那一次点击就落到窗口上 —— 任务没藏成，还会冒出「插件导致界面行为失效」。

现在：**光标在任务日志里时，Shift 直接放行**，插件什么都不做。
详情窗只在世界地图的任务图标上用 Shift 打开（那才是它的本职）。

## 2) 野外随手按 Alt 也弹窗

`C_QuestLog.GetSelectedQuest()` 记的是「上一次点过的任务」，鼠标挪开也不会清空。
1.5.25 拿它当兜底，结果地图没开、人在野外，随便按一下 Alt 就弹出上次那个任务
（你截图里反复弹的 #93443）。

现在：「日志选中行」**只在光标确实压在任务日志里**时才认。

## 3) 顺带修好了「鼠标下没识别到行」

你之前看到的 `用的是任务日志里选中的那条：#93443（鼠标下没识别到行…）`，
根因是那些行按钮的 `IsMouseOver()` 在这个客户端**一律返回 false**。

这一版加了一条**纯几何**的判断：算光标在不在帧的矩形里，完全不看 `IsMouseOver()`。
光标压在行上 → 直接认出这一行 → Alt 弹的就是它，不再退回「选中的那条」。

## 另外

- 鼠标不在任务日志里时按 Alt 不再往聊天框播报（以前会刷屏）
- 血量数值显示仍然停用（1.5.26 起），任务链、悬停面板、详情窗、小地图按钮照旧

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

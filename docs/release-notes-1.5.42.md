# 1.5.42

**地图图标：收掉 Questie 的提示框，只留我们自己的框**

判据修好之后（1.5.41）这个功能终于能用了。你截图里那种「上面 Questie 一大片 + 下面我们的卡片」，
现在只留下面那个。

## 现在的行为

- 悬停地图任务图标 → 我们认出任务 → 画我们的面板（贴光标）→ **把 Questie 的提示框按掉**
- **铁律**：只有我们的面板**真的显示着**，才允许按掉它的框；我们画不出来就立刻交还，
  绝不出现「两边都没有」
- 光标离开（距离超过 180px）或地图关掉 → 面板收起，并把 Questie 的提示框**叫回来**

## 阈值

Questie 的图标手柄很大（矩形只有 17×17，光标常在 60~80px 外），所以：
- 面板「还在」的判据：离图标中心 ≤ 120px
- 「离开」的判据：离接管点 > 180px

## 开关

设置里那一行还在：**「地图图标只显示本插件的面板（隐藏 Questie 提示框）」**，默认**开**。
想两个都看，取消勾选。

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

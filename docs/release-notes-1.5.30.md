# 1.5.30

**改成「松开 Shift 才弹窗」——按下那一刻什么都不做**

前面几版一直在研究「怎么判断鼠标在不在任务日志里」，越判越复杂，还是漏。
这次换思路：**不在按下时弹，等松开再弹。**

## 现在的行为

- **按下 Shift**：插件什么都不做。这一次点击能完整落到任务行上，
  Questie 的「Shift+左键隐藏/显示任务」照常生效 —— 不会再被窗口挡住
- **松开 Shift**：点击早就结束了，这时把鼠标下这个任务的整条链弹出来
- 任务日志里、地图上的任务图标上，行为一样
- 关掉地图之后再松开 Shift 不会凭空弹（这条老约束保留）
- Alt 仍然可以开窗，`/qct logkey` 可改

## 撤掉的

- **Shift+右键** 那套手势（你说被别的功能占着）
- **Alt+左键** 那套手势（只保留上面这一套，少一个组合键就少一处打架）
- 「按下 Shift 就弹」的老逻辑

## 一个提醒

Shift+点击隐藏任务之后，**松开 Shift 时会弹一次任务链窗**（因为手势就是"松开弹"）。
隐藏本身已经生效了，只是会多一个窗口，按 Esc 或点掉即可。
如果觉得这样太吵，告诉我，我可以加一条「夹着点击的那次松开不弹」的规则。

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

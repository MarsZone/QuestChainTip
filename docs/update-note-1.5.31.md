# 1.5.31 更新说明（简版）

**修了一个误触发：背包里悬停物品按 Alt，会弹出「任务日志第 N 个任务」**

原因两个，都修了：

1. 整合包（如 EllesmereUI）菜单栏上那个 `EUI_MicroMenu_QuestLog` 微型按钮，名字带 QuestLog，
   被插件当成了任务日志面板 → 以为日志一直开着。现在只认真正的日志面板。
2. 兜底逻辑把背包格子的 `GetID()` 当成了日志行号，而背包格子 ID 就是槽位号 1、2、3…
   → 放第 1 格弹第 1 个任务、第 2 格弹第 2 个。现在背包 / 动作条 / 银行 / 商人等容器里的
   格子一律不参与任务识别。

**顺手加了个新东西**：对着「任务起始物品」按住 Alt，直接看它开启的整条任务链
（背包、银行、邮件都行；不是起始物品就什么都不弹）。

覆盖安装后 `/reload` 即可。

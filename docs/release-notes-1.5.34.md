# 1.5.34

**悬停面板重新排版：区块分开、层级清楚，不再糊成一片**

## 改了什么

| 位置 | 以前 | 现在 |
|---|---|---|
| 抬头下面 | 直接进「任务描述」 | 先给一行**接取 / 交付**：NPC 名 + 地图 |
| 区块之间 | 没有间距，标题和正文糊在一起 | 留 7px 空白 |
| 区块标题 | 灰色（和正文同色） | **暗金色**，一眼能扫到 |
| 正文 | 缩进 3 空格 | 统一 2 空格 |
| 后续任务 | 纯列表 | `→` 标方向，右侧**经验压灰、状态保持彩色** |
| 前置任务 | 纯列表 | `←` 标方向 |
| 奖励 | 经验/金钱/物品/声望可能挤一行 | 经验+金钱一行、物品一行、声望各自一行 |

以前后续任务那一列是「1,400经验 (条件不足)」全红一团，看着像报错；
现在经验是灰色、只有状态标签是红的，奖励和状态一眼就分得开。

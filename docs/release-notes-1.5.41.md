# 1.5.41

**面板不回来的真因：判据太严**

你这份 `/qct map` 把问题钉死了：

```
持有者: QuestieFrame803 | 类型: map | 接管开关: 关
图标矩形: 589,484 17x17
光标: 674,555
解析到的任务: 605
```

- 提示框是**显示**着的、持有者是 Questie 的图标、任务也解析到了（605）
- 但**光标离图标中心大约 68 像素**（图标矩形只有 17×17）
  —— Questie 图标的可点区域比这个矩形大得多

1.5.35 我加的那条「光标必须在图标矩形里（±12px）」于是**永远判成「已离开」**，
面板刚画出来就被自己收掉 —— 这就是"什么都不显示"的真正原因（不只是接管开关）。

## 这一版

判据改成：**光标离图标中心不超过 120 像素**。

- 容得下 Questie 那种大手柄
- 又足够挡住「鼠标切到另一个图标、旧目标还没清」的情况

## 装完请试

`/reload` → 鼠标停那个黄色 `!` → 我们的面板应该**贴光标出现**了
（默认不接管，所以 Questie 的提示框同时也在；这版先确认我们的能出来）。

如果想「只留我们的」，再去设置里勾上那一行，我再看效果。

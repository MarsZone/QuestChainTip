# 1.5.37

**地图图标：把 Questie 的提示框收掉，只留我们自己的框**

## 现在悬停地图上的任务图标

1. 我们认出这一格的**任务** → 先在自己这边画面板（贴光标，带框），
2. 然后把 Questie 那个「NPC + 任务描述 + 奖励 + 后续」的长提示框**按掉**；
3. Questie 要是又弹回来，0.12 秒内继续按掉；
4. 光标离开图标（或地图关掉）→ 我们的面板自动收起。

## 认不出任务的时候

比如鼠标停在 NPC 标注上（那种图标没有任务 ID）—— **不动 Questie 的提示框**。
宁可按原样显示，也不要给你一片空白。

## 开关

设置里新增一行：**「地图图标只显示本插件的面板（隐藏 Questie 提示框）」**，默认**开**。
想回到以前（Questie 和我们的都显示），把这行取消勾选即可。

## 另外

- `/qct mute` 只是排查开关，**不跨会话保留**：每次登录都从「不静音」开始，忘了关也不会突然没反应
- Shift 手势保持原样（1.5.36 已经撤回改键）

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

# 1.5.38

**修 1.5.37 的「什么都不显示」**

## 为什么会全空

1.5.37 的逻辑是：解析出任务 → 画我们的面板 → 把 Questie 的提示框按掉。
问题出在中间那步可能"没画出来"，而按掉那步照做了：

1. **图标拿不到矩形**（这客户端 `GetRect` 不一定给值）→ 下一帧就判成「鼠标已离开图标」→ 面板刚画就被收走
2. 只要解析出任务 ID 就按掉 Questie，没有校验我们到底画没画

## 这一版

- 压制条件加铁律：**只有我们自己的面板真在显示，才允许按掉 Questie 的框**；
  我们画不出来就立刻交还，绝不出现「两边都没有」
- 离开判断改成两条：图标矩形命中（有矩形时）**或** 光标离接管点 60px 内；
  矩形取不到时走后者，不再误判
- 新增 **`/qct map`** 诊断：世界地图开没开、我们的面板显不显示、正在接管哪个图标、
  提示框持有者、图标矩形、光标坐标、解析到的任务 —— 断在哪一环一眼可见

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

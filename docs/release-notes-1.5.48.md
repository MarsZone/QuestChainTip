# 1.5.48

**详情窗按「哪里有空」自动摆放**

以前窗口固定 `CENTER`（拖过之后就一直停在那儿），所以你看到它总从同一个角落冒出来，
把要看的地图和任务列表挡住。

## 现在的摆放规则

1. 打开时先看光标位置
2. **优先摆在光标右侧 26px**
3. 右边放不下 → **翻到光标左边**
4. 上下贴边 → 整体收回来（底边不低于 12px、顶边不超出屏幕）
5. 窗口是左上角往下画的，所以让它的**竖直中线对着光标** —— 视觉上不会一边高一边低

## 你拖动过之后

拖动过一次就尊重你的位置：本次会话里不再自动摆（`/reload` 后恢复自动）。

## 回归测试

新增 `tests/run_test_window_place.lua`，四种情况都验了：

- 光标在中间 → 窗口在右边 26px、竖直居中
- 光标贴右边 → 翻到左边
- 光标贴底边 → 整体抬起，底边不低于 12px
- 拖动过 → 保持玩家位置

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

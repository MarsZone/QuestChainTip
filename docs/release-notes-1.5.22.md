# 1.5.22

**血量数字贴不上那个框？现在可以直接拖上去；任务日志改用「选中行」定位**

## 一、血量：你的目标框是客户端自己画的

排查结论：你屏幕上方那个目标框，**Lua 里拿不到**。

- 它不是任何插件的帧（`AddOns` 里没有插件创建单位框体，RurutiaSuite 的「姓名板目标」
  只是给姓名板加一行「目标的名字」，不建目标框）
- 它**没有名字** —— `/qct health scan` 在你机器上只列出了一个 `TargetFrame`（就是右下角那个）
- 它也不在 `UIParent` 下面，所以按名字找、按层级找都找不到

这种情况没法把文字「贴」上去，只能**盖上去**。所以新增了自由摆放模式：

```
/qct health float
```

执行后屏幕上方正中会出现「当前 / 最大」，**按住数字就能拖动**，拖到你的血条上松手即可，
位置自动保存，下次进游戏还在。拖一次会自动锁定，避免一直挡着下面框体的点击；
想再挪就 `/qct health move`。

想回到「跟随框体」：`/qct health auto`。
设置界面里也加了开关：**「血量数值可拖动（自由摆放）」**。

## 二、`/qct health scan` 现在能列出无名帧了

以前只列「有名字」的帧，所以列表里只有 `TargetFrame` 一个，根本找不到你要的那个。
现在走客户端的全量帧遍历，**无名帧也会列出来**，每项带序号：

```
  1. TargetFrame 位置(870,570) 尺寸137x44 [有血条]
  2. <无名> 位置(641,32) 尺寸252x48 [有血条]
```

对着屏幕看坐标，找到你那个框后直接：

```
/qct health pick 2
```

不用知道它叫什么名字。（`/qct health reset` 恢复自动）

## 三、「血量文字已挂到 …」为什么一直不出现

那行播报的代码里写成了 `self.announced`，但那个函数没有 `self`，一执行就抛错，
被外层 `pcall` 吞掉了 —— 数字照常显示，播报永远不出现。已修。

## 四、任务日志按 Alt：不再猜帧名，改读「选中行」

这个客户端有两个硬限制，前几版都栽在上面：

| 事实 | 后果 |
|---|---|
| 没有 `GetMouseFocus` | 「按键那一刻鼠标在哪」这条路整条作废 |
| 没有 `QuestLogTitleButton_OnEnter` | 连全局钩子都挂不上，行按钮钩子更挂不上 |

所以改成**完全不看鼠标**：读任务日志当前**选中的那一条**。

1. 在任务日志里**点一下**任务行（让它选中）
2. 按 **Alt**

就能打开那条任务的详情窗。任务 ID 从 `GetQuestLink` 里抠（任务日志里 shift+点击
能把任务链接贴到聊天框，说明这个字符串拿得到），不依赖标题文本（标题是 secret value）。

另外：

- 任务日志帧不再按名字猜 —— 扫 `_G` 里所有名字带 `QuestLog` 的帧当候选根，改名也能覆盖
- 提示框正显示着别的对象（物品 / NPC）时，Alt 不会被抢
- 按 Alt 没开窗时会自动播报现场，把这两行发作者即可定位：

```
按 Alt 没找到任务 | 日志帧: ... | 选中: 3 | 条目: 12 | 提示框: 隐藏 | 持有者: 无
  能定位到的任务: nil | 来源: nil | GetMouseFocus: 无 | GetQuestLink: 有 | GetQuestLogSelection: 有
```

## 五、顺手修的性能问题

血量一个候选框体都没找到时，之前**每次血量变化都会重扫全屏 + 全量遍历帧**，
战斗中会明显掉帧。现在限流 3 秒一次。

# 1.5.39

**先把「收掉 Questie 提示框」关掉，回到能正常显示的状态**

你的诊断输出很关键：`世界地图: 开 | 我们的面板: 隐藏 | 接管中的图标: 无 | GameTooltip: 隐藏`
—— 说明提示框是被我们按掉的，然后我们自己的面板又因为「判成鼠标已离开」被收起，
于是两边都空了。

## 这一版

- **这个功能默认关闭**（设置里那一行保留，勾上才启用）
- 离开判断只保留一条稳定判据：**光标离接管点超过 80 像素**
  （原来还看「光标在不在图标矩形里」，这个客户端上矩形不可靠，会瞬间误判）
- 收面板时把被按掉的 Questie 提示框**重新叫回来**（重发一次图标的 OnEnter），不再留空屏

## 现在的行为

默认和 1.5.36 一样：悬停地图图标 → Questie 的提示框照常显示 + 我们的小卡片也在。
不勾那个选项，就不会有任何东西被吞掉。

## 麻烦你帮我确认一件事

在**默认（不勾选）**状态下，鼠标停在那个黄色 `!` 上敲一次 `/qct map`，
把几行发我：

```
世界地图: ? | 我们的面板: ? | 接管中的图标: 无
GameTooltip: 显示/隐藏
  持有者: xxx | 类型: map/nil
  图标矩形: ... | 光标: ...
  解析到的任务: xxx
```

有了这组干净数据，我就知道是「GameTooltip 压根没显示（那 Questie 用的是别的框）」，
还是「显示了但我没认出来」，再动手才不会又白改一版。

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。

## 任务链提示 1.5.13 / Quest Chain Tip 1.5.13

窗口宽度不再固定死；修物品提示被任务描述盖住。

Panel and chain window widths are now configurable, and item tooltips are no longer hidden behind the chain window.

---

### 宽度可调 / Configurable width

玩家反馈：任务框宽度是固定的，一行信息显示不全就被迫换行。

- **悬停面板宽度**：窄 300 / 标准 380 / 宽 460
  （原来写死 330，默认改成 380，短任务名不容易被右侧的经验/金钱挤到第二行）
- **详情窗宽度**：自动（默认）/ 窄 480 / 标准 580 / 宽 720
  「自动」按屏幕逻辑宽度的 44% 算，夹在 420~900 之间；1080p 下大约 760

命令行：

```
/qct width auto      详情窗宽度自动
/qct width 720       详情窗固定 720
/qct pwidth 460      悬停面板 460
```

设置界面 →「悬停面板宽度」「详情窗宽度」两行，点按钮循环切换，改动即时生效（窗口开着会按新宽度重排）。

### 修物品提示被遮挡 / Item tooltip no longer covered

鼠标移到任务奖励物品上时，详情窗（`DIALOG` 层）压在物品提示上面，物品名和属性只剩几个字露出来。

现在悬停奖励物品时会把提示框顶到 `TOOLTIP` 层最高级，物品信息永远完整可见——代价是它会盖住窗口一角，这是正常的 tooltip 行为。

### 其它 / Also

- `toc` 简介改成「按住快捷键（默认 Shift，可改）」，不再写死 Shift
- 详情窗每次打开都重新算一次宽度，换分辨率或改设置后不用重载

### 测试 / Tests

- 10 条宽度断言：面板 / 详情窗宽度解析、越界夹取（240~560 / 420~900）、应用到窗口后正文宽度同步
- 4 条物品提示层级断言：层级提到 TOOLTIP、层级足够高、确实显示
- 本地化断言 51 条，覆盖新增文案（简 / 繁 / 英）

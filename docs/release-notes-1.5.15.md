## 任务链提示 1.5.15 / Quest Chain Tip 1.5.15

任务列表也能按快捷键弹详情窗；新增血量数值和小地图按钮。

The quest log now opens the chain window with a hotkey, plus optional health values and a minimap button.

---

### 任务日志列表 / Quest log

鼠标停在任务行上，按住 **Alt**（默认）→ 打开整条任务链详情窗。

为什么不用 Shift：任务日志里 Shift+点击是原生的「把任务链接贴到聊天框」，抢掉玩家就没法复制任务链接了。所以这条路单独一个键。

- 设置里「任务日志快捷键」：Alt（默认）/ Ctrl / 不启用
- 命令：`/qct logkey alt|ctrl|none`
- 世界地图的「详情窗快捷键」不受影响，两个键各管各的

### 血量数值 / Health values

目标框体、焦点框体的血条上显示「当前 / 最大」，例如 `1998 / 1998`。

- **默认关闭**，设置里勾「显示血量数值（目标/焦点血条上）」
- 只在血条上叠一层文字，不改框体布局；目标消失时自动清空
- 自定义 UI 改了框体结构也能用：递归找第一个 StatusBar 当血条

### 小地图按钮 / Minimap button

小地图边缘多一个图标：左键打开设置，拖动可以换位置（角度会记住）。

- 设置里「显示小地图图标」可以关掉
- 和小地图其它按钮一样的圆环边框

### 测试 / Tests

- 任务日志快捷键 9 条断言：默认 Alt、Alt 开窗、Shift/Ctrl 不开、改成 Ctrl 后行为跟着变、不启用全关
- 血量 9 条断言：默认关闭时不建文字、满血/掉血/目标消失/关掉开关
- 小地图按钮 11 条断言：创建、父级、点击开设置、悬停提示、开关

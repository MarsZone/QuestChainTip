# 1.5.36

**Shift 恢复原样 + `/qct mute` 静音排查**

## 1) Shift 没动

1.5.35 那个「Shift 自动改成 Alt」的迁移**撤掉了**。
已经跑过那次迁移的存档会自动改回 Shift（只改一次，之后你自己 `/qct key` 的选择不会再被覆盖）。

## 2) 先用静音确认「弹窗是谁弹的」

```
/qct mute on      ← 本插件彻底闭嘴：不画面板、不开详情窗、按键也不响应
（然后按住 Shift 悬停地图图标，看还有没有那一大段字 / 弹窗）
/qct mute off     ← 恢复
```

静音状态下如果**还有**那一大段「NPC + 任务描述/奖励/后续」——那就是 Questie 的
（它靠 `IsShiftKeyDown()` 决定展开详情），跟我们无关，要继续清就关 Questie 那个选项；
如果**没有**，就确实是我们画的，我再按这个方向收。

静音时登录会提示一行「插件处于静音状态」，不会让你以为插件坏了。

## 3) 保留的两条 UI 修正

- 面板贴着光标弹（以前贴在 Questie 那个高提示框下面，离鼠标几百像素）
- 光标离开图标就不再画（提示框收得比鼠标慢半拍）

## 安装

覆盖 `Interface\AddOns\QuestChainTip`，`/reload`。
